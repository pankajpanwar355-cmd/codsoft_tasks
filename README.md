# CODSOFT Python Programming Internship Tasks

This repository contains three beginner-friendly command-line Python projects from the CodSoft Python Programming internship task list.

## Requirements
- Python 3.8 or newer
- No third-party packages are required

## Task 1: To-Do List
File: `task1_todo_list.py`

Features:
- Add a task
- View all tasks
- Update a task
- Mark a task complete or pending
- Delete a task
- Save tasks in `tasks.json`, so they remain after closing the program

Run:
```bash
python task1_todo_list.py
```

## Task 2: Calculator
File: `task2_calculator.py`

Features:
- Addition, subtraction, multiplication, and division
- Input validation
- Division-by-zero protection
- Option to perform multiple calculations

Run:
```bash
python task2_calculator.py
```

## Task 3: Password Generator
File: `task3_password_generator.py`

Features:
- User chooses the password length
- Optional numbers and symbols
- Uses Python's `secrets` module for secure random selection
- Includes lowercase and uppercase letters

Run:
```bash
python task3_password_generator.py
```

## GitHub submission
1. Create a GitHub repository named `CODSOFT_TASKSNO` (or use the exact naming format instructed by your internship coordinator).
2. Upload these three `.py` files and this README.
3. Run each program and record a short demo video showing its features.
4. Submit the repository link using the official task submission form when CodSoft shares it.

## Important
These are command-line versions of the projects. Review the code, run all three programs, and make sure you can explain the features in your own words before recording your demo.
